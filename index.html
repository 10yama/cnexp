ネットワーク観察ラボ

Chrome のデベロッパーツール（DevTools）で、Web の通信を観察するための練習用ページです。

はじめに

  1. Chrome で DevTools を開く（Windows: F12 または Ctrl+Shift+I／Mac: ⌘+Option+I）
  2. 「Network（ネットワーク）」タブを選ぶ
  3. DevTools を開いたまま、下のリンクをクリックする
  4. 列の見出しを右クリックすると「Protocol」「Remote Address」「Domain」などの列を追加できる

観察する実験ページ

  1. いちばん小さいページ — HTML ファイル 1 つだけ
  2. 部品でできたページ — HTML ＋ CSS ＋ 画像 ＋ JavaScript
  3. 大きな写真のページ — 約 2.8MB の写真を 1 枚
  4. フォームのページ — GET と POST で送ってみる
  5. 存在しないページへのリンク — ステータスコードを見てみよう

比べてみるほかのサイト

  • http://httpforever.com/ — わざと https にしていない（暗号化しない）サイト。Chrome が「保護されていない通信」と警告を出すので、内容を確認して「サイトに移動」で進む
  • https://example.com/ — 説明用に予約されたドメインの、とても小さなページ
  • https://www.kaetsu.ac.jp/ — ふつうの大学サイト。リクエストの数を比べてみよう
