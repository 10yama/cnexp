# ネットワーク観察ラボ

授業「コンピュータネットワーク」で、Chrome DevTools を使って Web の通信を観察するための演習用ページです。

| ページ | 中身 | リクエスト数（目安） |
|---|---|---|
| `01-minimal.html` | HTML だけ | 1 |
| `02-parts.html` | HTML ＋ CSS ＋ JavaScript ＋ 画像 | 4 |
| `03-big.html` | 約 2.8MB の写真 | 3 |
| `04-form.html` | GET / POST フォーム（POST は GitHub Pages が 405 を返す） | 2 |
| `result.html` | GET で送ったクエリを表示 | 2 |
| `404.html` | 存在しないページ用（ステータス 404） | 1 |

収録した動画と中身がずれないよう、公開後はなるべく変更しないこと。
